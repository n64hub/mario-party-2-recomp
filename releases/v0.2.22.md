A widescreen fix for the startup logos. Like v0.2.21 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `166eda1c05670d337e2c3f15a5db528ae1e5d6e3`). Other regions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioParty2Recompiled-v0.2.22-windows-x64.zip` and run `MarioParty2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioParty2Recompiled-v0.2.22-linux-x64.tar.gz` and run `MarioParty2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**Fixed:**

- In a wide window, the startup logos (Nintendo 64, Nintendo, Hudson) now keep their shape, centred at 4:3 with black at the sides. Before, each was stretched to the window's width ([#124](https://github.com/n64hub/mario-party-2-recomp/issues/124)).

**Not checked yet:** long play sessions, rumble on a physical pad (it was played in the browser with stand-in pads), and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Reports are welcome on the [issues page](https://github.com/n64hub/mario-party-2-recomp/issues).

The [README](https://github.com/n64hub/mario-party-2-recomp#readme) has what works and how to build it yourself. The same game also plays in a browser, with your ROM, at [n64hub.com](https://n64hub.com/#mario-party-2).
